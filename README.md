# partsledger

Inventory and pricing ledger for a parts distributor. Fastify, Postgres, TypeScript.

## About this repository

**This is a sample repository.** The service is fictitious, the suppliers and
parts are invented, and the commit history and its pull
requests were generated by `tools/build-history.sh` and
`tools/open-pull-requests.sh` rather than recorded from real work — including the
dates, the authors and the co-author trailers on it.

It exists to give a provenance tool a realistic repository to read: a year of
commits, a mix of human and agent-assisted work, schema migrations that alter
live tables, and commits that carry no provenance signal at all.

Nothing here should be read as a record of who wrote what in the real world.

## Running it

```bash
cp .env.example .env
npm install
npm run migrate
npm run dev
```

Requires Postgres 14 or newer. `DATABASE_URL` must point at a database you are
happy to have migrated.

## Layout

```
src/config.ts          environment parsing, fails fast on a bad value
src/db/pool.ts         pooled access and a transaction helper
src/lib/               error taxonomy and the request logger
src/routes/            health, parts, orders
src/services/pricing   quantity bands, loyalty accrual, rounding
src/services/ledger    append-only stock movements
migrations/            plain SQL, applied in filename order
```

## Invariants

- Stock is never stored as a running total. It is the sum of `stock_movements`.
- A movement may not take a part negative; the check happens inside the
  transaction that writes it.
- A quote rounds to the nearest cent, and a discount is capped at 2500 basis
  points regardless of what is passed in.
